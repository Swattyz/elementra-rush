# Elementra RUSH

"Um RPG de turnos que se passa no mundo de **Elementra**, onde os elementos naturais é a base da magia. Escolha um entre os quatro elementos primordiais e enfrente a besta primordial do fogo que renasceu diretamente das chamas ferventes do **Purgatório Carmesim**, **Dhrygon**!"

Um pequeno e simples jogo independente feito por uma __equipe de 7 pessoas para uma feira de ciências__.

## Controles

- WASD / Arrow Keys — Andar / Seleção
- Space / Enter — Confirmar
- Esc — Sair
- F11 — Minimizar/Fullscreen

## Como jogar

- Inicie o jogo e escolha o elemento de preferência;
- Encontre o chefe do jogo "Dhrygon" e o enfrente;
- O jogo possui como base o combate em turnos com ações baseadas em **Quick-Time Events (QTE)** estilo Undertale;
- Em versões mais futuras, a parte visual dos QTE poderão ser desativadas devido ao uso de eletrônica para a feira de ciências, que substituirá a barra de acerto visual no jogo por um LED otimizado.
